# نمایش تاریخ

## نمایش از طریق view

`format($pattern)` را روی view تقویم صدا بزنید. formatter توکن‌های جدول زیر را پشتیبانی می‌کند، نه همه توکن‌های تمام نسخه‌های PHP را. کاراکتر ناشناخته بدون تغییر در خروجی می‌آید. برای نمایش خود حرف یک توکن، قبل از آن بک‌اسلش بگذارید. تبدیل view به رشته از قالب `Y-m-d` برای میلادی و `Y/m/d` برای بقیه تقویم‌ها استفاده می‌کند.

```php
<?php
require 'vendor/autoload.php';

use Eram\Daynum\CivilDateTime;

$v = CivilDateTime::fromGregorian(2026, 4, 8, 14, 30, 0, 'Asia/Tehran')
    ->jalali()->withLocale('fa')->withDigits('persian');
echo $v->format('Y/m/d H:i P'), "\n";
echo $v->format('c'), "\n";
echo $v->format('\\Y Y'), "\n";
```

```text
۱۴۰۵/۰۱/۱۹ ۱۴:۳۰ +03:30
2026-04-08T14:30:00+03:30
Y ۱۴۰۵
```

## مرجع توکن‌ها

| توکن‌ها | معنی |
|---|---|
| `Y y` | سال تقویم با حداقل چهار رقم / دو رقم آخر |
| `m n F M` | ماه با صفر ابتدایی / بدون صفر / نام کامل / نام کوتاه |
| `d j S` | روز با صفر ابتدایی / بدون صفر / پسوند ترتیبی زبان |
| `l D N w` | نام کامل و کوتاه روز هفته؛ شماره روز با دوشنبه=1 یا یکشنبه=0 |
| `z` | شماره روز سال از صفر؛ `dayOfYear()` از یک شروع می‌شود |
| `W o` | شماره هفته و سال هفته بر اساس قانون پنجشنبه در همین تقویم |
| `t L` | تعداد روزهای ماه / نشانه سال کبیسه |
| `H G h g` | ساعت ۲۴ ساعته با صفر و بدون صفر؛ ساعت ۱۲ ساعته با صفر و بدون صفر |
| `i s a A` | دقیقه، ثانیه و نشانه قبل یا بعد از ظهر در زبان انتخابی |
| `u v` | همیشه `000000` و `000`؛ دقت کمتر از ثانیه ذخیره نمی‌شود |
| `e T` | برچسب ذخیره‌شده منطقه زمانی / نام اختصاری منطقه زمانی از PHP |
| `O P p Z I U` | اختلاف ساعت، اختلاف با دونقطه، اختلاف یا Z، اختلاف به ثانیه، وضعیت DST و ثانیه Unix |
| `c r` | خروجی میلادی ISO 8601 و RFC 2822 از PHP |

توکن‌های `e T O P p Z I U c r` به برچسب منطقه زمانی غیر `null` نیاز دارند. به‌جز `e` که خود برچسب را چاپ می‌کند، بقیه از PHP برای تشخیص منطقه زمانی استفاده می‌کنند و ممکن است برچسب نامعتبر را رد کنند. ارقام خروجی این توکن‌ها تبدیل نمی‌شوند. `c` و `r` حتی روی view شمسی یا قمری هم تاریخ میلادی می‌دهند؛ بقیه توکن‌های تقویمی از تقویم انتخاب‌شده استفاده می‌کنند. در ساعت‌های حذف‌شده هنگام تغییر ساعت رسمی، PHP ممکن است ساعت محلی را اصلاح کند؛ [راهنمای منطقه زمانی](timezones.md) را ببینید.

`W` و `o` ممکن است در مرز محدوده خطا بدهند و شروع هفته در locale روی آن‌ها اثر ندارد. `S` به زبان بستگی دارد و در فارسی و عربی خالی است. locale عربی نام ماه شمسی ندارد و `F` و `M` در این حالت خطا می‌دهند. پیش از اینکه فرض کنید هر خروجی را می‌توان دوباره خواند، [راهنمای زبان و ارقام](localization.md) و [parsing](parsing.md) را بخوانید.
