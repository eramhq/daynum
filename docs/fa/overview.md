# آشنایی با Daynum

Daynum یک کتابخانه تغییرناپذیر PHP برای تبدیل، نمایش و محاسبه تاریخ در تقویم میلادی، شمسی و دو نوع تقویم قمری است. به PHP 8.1 یا بالاتر نیاز دارد، وابستگی Composer برای اجرا ندارد و بدون `ext-intl` کار می‌کند.

## وضعیت انتشار

این راهنماها همراه نسخه [v1.0.0-beta.4](https://github.com/eramhq/daynum/releases/tag/v1.0.0-beta.4) به تاریخ ۸ اکتبر ۲۰۲۶ هستند. این نسخه آزمایشی است و هنوز نسخه پایدار 1.0 نیست. راهنماهای دوزبانه، بررسی سخت‌گیرانه‌تر AM/PM و اختلاف ساعت تکراری و بهبود تطبیق نام‌ها در این نسخه قرار دارند. [راهنمای parsing](parsing.md#تغییرات-parsing-در-beta4) رفتارهای اضافه‌شده در beta.4 را مشخص می‌کند؛ beta.3 این تغییرات را ندارد. [changelog نسخه](../../CHANGELOG.md#100-beta4--2026-10-08) را ببینید.

|---|---|---|
| [میلادی](calendars/gregorian.md) | `fromGregorian()` / `gregorian()` | -9999 تا 9999، شامل سال صفر |

`CivilDateTime` روز، ساعت محلی و یک برچسب اختیاری منطقه زمانی را نگه می‌دارد. تبدیل تقویم، ساعت و این برچسب را حفظ می‌کند و زمان یک لحظه را به منطقه زمانی دیگری تبدیل نمی‌کند. برای این کار از `DateTimeImmutable` در PHP یا timestamp استفاده کنید؛ جزئیات در [راهنمای منطقه زمانی](timezones.md) آمده است.
